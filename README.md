# くにっこ バス時刻表

国立市のコミュニティバス「くにっこ」の時刻表Webアプリです。

https://fadysan-rh.github.io/kunikko-bus-schedule/

## 機能

- **次のバス表示** - 現在時刻から次に来るバスをリアルタイムで確認
- **停留所検索** - 出発・到着の停留所を選択してルートを検索
- **ルート対応** - 北・北西中ルートなど複数ルートに対応
- **往路・復路切り替え** - ワンタップで方向を切り替え
- **途中停留所表示** - 経由する停留所の一覧を確認
- **運賃情報** - 大人・小児の運賃を表示（未就学児は引率者1人につき1人まで無料）

## 運行情報

- 平日も土休日もダイヤは同じです
- 渋滞などで遅れることがあります
- 運行に関する問い合わせ先: 国立市道路交通課
